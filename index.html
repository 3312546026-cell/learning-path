学习任务规划

C 语言→51 单片机

面向两类学生的完整嵌入式入门路线，从语法基础到硬件编程，一条路径走通。

选择你的起点

根据现有基础，选择最适合的学习节奏。

有基础
快速进阶

已掌握至少一门语言的基本语法，可快速回顾 C 语言特性，重点攻克指针与内存模型。

  • 起步直接进入翁恺 C 语言课程
  • 重点指针、结构体、内存管理、文件 IO
  • 节奏1.5 倍速过基础，暂停做进阶练习
  • 目标能独立编写含指针与结构体的 C 程序
零基础
系统入门

从零开始，需要系统建立编程思维，从变量与流程控制一步步打牢地基。

  • 起步从黑马程序员 C 语言全套开始
  • 重点数据类型、运算符、循环、函数、数组
  • 节奏正常速度跟练，每节配套手写代码
  • 目标理解编程逻辑，能读懂并修改基础 C 代码

学习路线

两条路径在第二阶段汇合，共同进入 51 单片机实战。

1

C 语言基础入门

有基础 1~2 周 · 零基础 3~4 周

建立 C 语言语法体系，能独立编写、编译和调试简单程序。

有基础路径
翁恺 C 语言程序设计，快速回顾语法，重点放在指针、结构体、联合体、枚举与内存操作上。每章配合 2~3 道编程题。
零基础路径
黑马程序员 C 语言全套，从变量、数据类型、运算符开始，循序渐进到函数、数组、指针、结构体。每节必须手写代码跟练。
2

进阶巩固与小项目

1~2 周

通过实战项目把语法转化为编程能力，查漏补缺。

共同任务
完成 2~3 个小项目：学生成绩管理系统（结构体+数组）、简易通讯录（指针+动态内存）、文件读写练习。零基础同学可回看翁恺课程进阶章节补充指针与内存管理内容。
3

51 单片机入门实战

2~3 周

理解单片机工作原理，能用 C 语言控制硬件外设。

共同任务
跟随 51 单片机入门教程，全程纯手打代码。依次掌握：GPIO 输入输出、LED 与按键、定时器与中断、串口通信、数码管与 LCD、传感器与外设驱动。最终完成一个综合小项目（如智能小车或环境监测仪）。
