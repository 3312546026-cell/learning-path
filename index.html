Roadmap

两条路线，最后汇合

有基础的人从复习开始，没有基础的人先建立 C 语言基础；之后分别深入下位机和上位机。

建议按顺序学习

下位机 · 硬件与控制

从代码基础到电路、焊接和嵌入式实战

⌁
  1. 1

    C 语言基础 共同起点

    有基础：复习指针、结构体、数组、函数与内存；无基础：从变量、流程控制、函数和数组开始。

  2. 2

    电工与电子技术

    认识电压、电流、电阻、二极管、三极管和常见电路，为看懂硬件打底。

  3. 3

    烙铁焊接

    学习元器件引脚识读、锡焊、拆焊和基础维修，真正开始动手。

  4. 4

    51 单片机

    掌握 GPIO、按键、LED、定时器、中断、串口和常见外设。

  5. 5

    PCB 设计

    使用嘉立创 EDA 完成原理图、PCB 布线和项目打板。

  6. 6

    STM32 单片机

    从 51 的基础过渡到更完整的嵌入式系统与工程化开发。

学习结果：能独立完成“电路设计 → 制作焊接 → 程序控制 → 调试验证”的完整闭环。

上位机 · 视觉与交互

Python 与 OpenCV、Java 与 Android Studio 并行推进

◌
  1. 1

    Python + OpenCV 一起学习

    学习 Python 基础、图像读写、颜色空间、滤波、轮廓和摄像头处理。

  2. 2

    计算机视觉实战

    通过图像处理项目，把原理转化为可运行的代码和可观察的效果。

  3. 3

    YOLO 环境配置

    配置视觉识别开发环境，理解模型运行、数据输入和结果输出。

  4. 4

    Java + Android Studio 一起学习

    学习 Java 基础、Android 界面、网络/串口通信和移动端交互。

  5. 5

    Linux 拓展

    熟悉命令行、环境配置、脚本和服务，为部署与嵌入式 Linux 做准备。

学习结果：能完成“数据采集 → 图像识别 → 设备通信 → 手机控制”的上位机应用。
